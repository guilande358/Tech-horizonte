# Tech Horizonte

Bem-vindo ao **Tech Horizonte**, um site dedicado a explorar as tecnologias mais inovadoras e transformadoras de 2025 e além! Aqui, você encontrará artigos detalhados sobre inteligência artificial, 5G, realidade virtual e muito mais, todos projetados para inspirar e informar.

## Sobre o Projeto
Este repositório contém o código-fonte de um site estático desenvolvido em HTML, CSS e JavaScript. O site apresenta uma interface amigável com uma grade de cards que levam a conteúdos específicos sobre tendências tecnológicas, ideal para entusiastas e profissionais da área.

## Como Usar
1. **Guilande358/Tech-horizonte/**:
2. **Abra o site**:
- Abra o arquivo `index.html` em um navegador web (ex.: Chrome, Firefox) para visualizar o site offline.
- Certifique-se de que os arquivos `styles.css`, `script.js` e a pasta `images` (se presente) estejam na mesma pasta.

### Online
- O site está hospedado no GitHub Pages. Após ativar a hospedagem (veja abaixo), acesse:
[https://guilande358.github.io/Tech-horizonte](https://guilande358.github.io/Tech-horizonte).
- Clique nos botões "Leia Mais" para carregar dinamicamente o conteúdo de páginas como `5G.html`, `IA.html`, etc.

## Estrutura do Projeto

- **`index.html`**: Página principal com uma grade de cards que listam os tópicos tecnológicos.
- **`IA.html`, `RV.html`, `Secure.html`, `5G.html`**: Páginas individuais com conteúdos detalhados sobre cada tema (ex.: 10 Melhores Tecnologias, IA e Futuro do Trabalho).
- **`styles.css`**: Arquivo de estilos para layout responsivo e design visual.
- **`script.js`**: Lógica JavaScript para carregar o conteúdo das páginas dinamicamente ao clicar em "Leia Mais".
- **`images/`**: Pasta opcional para imagens relacionadas aos artigos (ex.: `Tech.png`, `RV.png`, `IA.png`).
- **`README.md`**: Este arquivo, contendo informações sobre o projeto.

## Instalação e Dependências
- Não requer instalação de softwares adicionais além de um navegador web moderno (Chrome, Firefox, Edge).
- Para desenvolvimento, recomenda-se um editor de código (ex.: VS Code) e o Git para clonagem.

## Hospedagem no GitHub Pages
Para tornar o site acessível online:
1. Vá em **Settings** > **Pages** no repositório.
2. Selecione a branch `main` como fonte e salve.
3. Aguarde 5-10 minutos para a publicação. O URL será [https://guilande358.github.io/Tech-horizonte](https://guilande358.github.io/Tech-horizonte).

## Contribuições
Quer ajudar a expandir o Tech Horizonte? Siga estas etapas:
- **Abra uma Issue**: Sugira novos tópicos ou relate bugs em [Issues](https://github.com/guilande358/Tech-horizonte/issues).
